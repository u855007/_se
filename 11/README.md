# 期末作品｜學習日誌 Edge Study Notes

**現代軟體工程 · 林峻德（31）**

學習日誌是一個繁體中文筆記網站，用來記錄上課重點、開發過程和實驗結果。使用者可以依分類整理筆記，也能用關鍵字快速找回以前的紀錄。

## 功能

- 新增、編輯、刪除筆記，可填寫標題、分類和內容。
- 依標題、內文或分類搜尋，也可用下拉選單篩選分類。
- 修改後自動儲存，重新整理頁面仍能看到筆記。資料使用瀏覽器的 localStorage，依瀏覽器及網址分開儲存。

## 啟動方式

有 Deno 2.8 以上版本時，可直接從 JSR 啟動：

```powershell
deno run --allow-net=127.0.0.1 jsr:@peter-dev/edge-study-notes@1.0.0 --port 8790
```

Windows 已安裝 Node.js、沒有獨立安裝 Deno 時，可用：

```powershell
npx.cmd --yes deno@2.9.6 run --allow-net=127.0.0.1 jsr:@peter-dev/edge-study-notes@1.0.0 --port 8790
```

執行後開啟 [http://127.0.0.1:8790](http://127.0.0.1:8790)，按 Ctrl+C 停止。若已下載原始碼，可參考[從原始碼啟動的方式](../10/README.md#jsr-備案deno-28-以上)。
