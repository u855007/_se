v2

Python Implementation

核心挑戰在於手動操作 Socket。我們使用 ssl.wrap_socket 實作 TLS 握手，並直接發送 UTF-8 編碼的 HTTP 請求字串。

特別實作了 Chunked Transfer Encoding 解碼邏輯，透過讀取 16 進位分塊大小來重新組合成完整內容。 

import socket
import ssl

# 關鍵實作：TLS 握手
context = ssl.create_default_context()
ssock = context.wrap_socket(sock, server_hostname=host)

# 關鍵實作：手動構建 HTTP 請求
request = f"GET {path} HTTP/1.1\r\nHost: {host}\r\nConnection: close\r\n\r\n"
ssock.sendall(request.encode('utf-8'))

# 關鍵實作：Chunked 解碼邏輯
# 讀取 hex size -> 讀取該長度數據 -> 跳過 \r\n -> 重複直到 size=0
v3

PowerShell Implementation

利用 .NET Framework 的底層類別 TcpClient 和 SslStream。

實作流程與 Python 相同，但需處理 .NET 的位元組流 (Byte Stream) 與字串編碼轉換，證明了 HTTP 協定在不同平台間的一致性。 

# 關鍵實作：.NET SslStream
$SslStream = New-Object System.Net.Security.SslStream($NetworkStream, $false)
$SslStream.AuthenticateAsClient($HostName)

# 寫入原始 UTF8 位元組
$RequestBytes = [System.Text.Encoding]::UTF8.GetBytes($Request)
$SslStream.Write($RequestBytes, 0, $RequestBytes.Length)
